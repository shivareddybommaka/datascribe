# Security review checklist (§10)

Every item of REQUIREMENTS.md §10 (non-functional requirements), with where it is enforced and
what checks it. Status as of 2026-10-24, branch `sentinel/m10` (M10 part 3a).

- **Done**: enforced in code and covered by a test.
- **Defined in IaC, not applied**: written in `infra/terraform` (D-115, `docs/INFRA.md`) and
  checked by `apps/api/test/infra-terraform.test.ts`, but never planned or applied. It becomes Done
  when Shiva approves Terraform and the environment is applied.
- **Partial**: some of it is in place; the rest is listed.
- **Open**: not built yet.

File paths are relative to the repository root. Test names are quoted so they can be searched.
