# M0 demo — Foundation

Account: `nova`. Run from the repo root (`~/projects/datascribe`).

## Checks (no infrastructure needed)

```
pnpm install
pnpm db:generate
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Expected: every task succeeds; `pnpm test` reports 90 passing tests with coverage above 80% for
`packages/shared` and `apps/api`.

## With infrastructure (needs Docker)

```
cp .env.example .env
docker compose up -d
pnpm db:migrate
pnpm db:seed
pnpm dev
```

Then:

- http://localhost:3000 — web placeholder (`/portal`, `/console`)
- http://localhost:4000/api/v1/health — `{"status":"ok"}`
- http://localhost:8025 — Mailpit
- http://localhost:9001 — MinIO console

Seed users (password = `SEED_USER_PASSWORD` from `.env`): `super.admin@datascribe.example`,
`ops.manager@…`, `case.manager@…`, `summarizer@…`, `qa.reviewer@…`, `sales@…`, `finance@…`,
`client.admin@acme.example`, `client.user@acme.example`, `client.admin@harbor.example`.
Login itself arrives in M1.
