# M7 demo — CRM

Account: `nova`. Repo root: `~/projects/datascribe`. Synthetic data only.

## Automated

```
pnpm --filter @datascribe/api test
```

```
pnpm --filter @datascribe/web e2e
```

- API: `test/crm.test.ts` ("M7 definition of done") runs website form → lead → convert → invite → admin
  signs in, plus access control, stage rules, tasks, contacts, CSV and accounts.
- E2E (needs `colima start` and `pnpm infra:up`): the same journey in a real browser, including the
  kanban drag and the invite email read from Mailpit. Starts its own API on :4100 and web on :3100
  against `datascribe_e2e`.

## By hand

```
colima start
```

```
pnpm infra:up
```

```
pnpm db:seed
```

```
pnpm dev
```

1. http://localhost:3000/contact?kind=demo, then submit the form (synthetic details).
2. http://localhost:8025 (Mailpit): "New website demo request" to `sales@datascribe.example`.
3. http://localhost:3000/console: sign in as `sales@datascribe.example` with `SEED_USER_PASSWORD`
   from `.env`. First login asks you to scan a QR code with an authenticator app (MFA is mandatory
   for staff).
4. Leads: the request is in New. Drag it to Contacted, open it, log a call, add a task due today
   (it appears in "My tasks today" on Overview).
5. Convert to client, then check Mailpit for the invite. Open the link and set a password.
6. Accounts: the new firm with its admin, contacts and history.
7. Try marking another lead Lost: a reason is required. Try Export CSV / Import CSV on Leads.
