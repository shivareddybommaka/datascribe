# M7 demo — CRM (API part)

Account: `nova`. Repo root: `~/projects/datascribe`. Synthetic data only.

## Automated

```
pnpm --filter @datascribe/api test
```

`test/crm.test.ts` → "M7 definition of done" runs the whole journey: website demo form → lead
(email to sales in the memory mailer) → stage change + call logged → convert with a plan → invite email →
admin accepts → admin signs in to the new firm.

## By hand (needs `colima start`, `pnpm infra:up`, `pnpm db:seed`, `pnpm dev`)

1. Submit a website lead (no login):

```
curl -s -X POST http://localhost:4000/api/v1/public/leads -H "content-type: application/json" -d '{"kind":"demo","name":"Robin Synthetic","company":"Brightwater Law (synthetic)","email":"robin@brightwater.example"}'
```

2. Open http://localhost:8025 (Mailpit): the "New website demo request" email to `sales@datascribe.example`.
3. Sign in as `sales@datascribe.example` (seed password + TOTP), then use the console CRM (M7b UI) or the API:
   - `GET /api/v1/leads?source=website_demo`
   - `PATCH /api/v1/leads/:id` with `{"stage":"qualified"}`
   - `POST /api/v1/leads/:id/convert` with `{}`
4. Mailpit now has "You're invited to Datascribe (Brightwater Law (synthetic))". Open the link, set a
   password, and sign in as the new firm's client admin.
