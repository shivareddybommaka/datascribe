# M4 demo — Client portal: cases and uploads

Account: `nova`. Repo root: `~/projects/datascribe`. Synthetic data only (Synthea-style names). Needs
Colima and the local infra (Postgres 5433, SeaweedFS S3 on 9000, Mailpit).

## Automated

```
pnpm --filter @datascribe/api test
```

```
pnpm --filter @datascribe/web e2e
```

- API `test/uploads.test.ts` "M4 DoD": builds a 300-page synthetic PDF (~12 MB, 3 parts of 5 MiB),
  uploads part 1, gets 409 `upload_incomplete` with the missing parts, asks the API what S3 already
  has, uploads only parts 2 and 3, completes, and checks SHA-256 = the file's, pageCount = 300, a
  5-minute signed download returns the same bytes, and the audit rows. Also: magic bytes, size limits,
  PNG/JPEG/TIFF, EICAR → quarantined, scanner failure → not downloadable, access rules.
- API `test/portal-cases.test.ts`: create/edit/submit, numbering, encryption at rest, list filters,
  sharing, messages (internal notes hidden), the L5 backfill, dashboard and firm MFA policy.
- E2E `e2e/portal.spec.ts`: the client signs in, creates a case, uploads the 300-page PDF while part 2
  keeps failing, sees "Interrupted", resumes (only part 2 is sent), waits for "Ready" with 300 pages,
  downloads it, submits the case and messages Datascribe. Then the client admin opens the case,
  invites a colleague and pays an invoice through the simulated checkout.

## By hand

```
colima start
```

```
pnpm infra:up
```

```
pnpm db:migrate
```

```
pnpm db:seed
```

```
pnpm dev
```

1. http://localhost:3010/portal → sign in as `client.user@acme.example` with `SEED_USER_PASSWORD` from
   `.env`. The dashboard shows Acme's open cases by status.
2. **New case**: fill in the matter, patient name (use a synthetic name such as `Ramiro608 Jacobs452`),
   type, deliverables. The case opens as **Draft** with its `DS-2026-…` number.
3. **Records**: drag in one or more PDFs, images or TIFFs. Each has a progress bar. Click **Pause**
   during a large upload, then **Resume**; or reload the page and choose the same file again: it
   continues where it stopped. When the scan finishes the file shows **Ready** with its page count
   and SHA-256. **Download** fetches it through a 5-minute signed link.
4. A PDF that contains the EICAR anti-virus test string (as `uploads.test.ts` builds) shows
   **Quarantined** and can't be downloaded. A `.zip` or `.exe` renamed `.pdf` is refused once uploaded,
   because the type is read from the file's first bytes.
5. **Submit to Datascribe**: the timeline gains "Submitted" and editing is locked. Send a message in
   **Messages with Datascribe**.
6. Sign out, sign in as `client.admin@acme.example`: every Acme case is visible; **Shared with** lets
   you share a case with a colleague. **Firm**: rename the firm, tick **Require two-factor
   authentication** (everyone sets up an authenticator at their next sign-in; untick it again), invite
   a colleague (the email is in Mailpit, http://localhost:8025). **Billing**: usage meter, change plan,
   cancel at period end, invoices; open an issued invoice and **Pay … by card** (simulated checkout
   without a Stripe test key).

Real virus scanning: `docker compose --profile scan up -d`, then set `CLAMAV_HOST=localhost` in `.env`
and restart the API (the ClamAV image needs a few minutes to load its signatures on first start).
