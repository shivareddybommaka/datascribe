# M3 demo — Marketing website + CMS

Account: `nova`. Repo root: `~/projects/datascribe`. Synthetic data only.

## Automated

```
pnpm turbo run lint typecheck test build --output-logs=errors-only
```

```
pnpm --filter @datascribe/web e2e
```

- `apps/api/test/public-plans.test.ts`: active plans only, money as strings, no internal fields.
- `apps/web/test/analytics-boundary.test.ts` + `lib/analytics.test.ts`: GA4/GTM never on app routes,
  never before consent.
- `apps/web/e2e/marketing.spec.ts`: the 7 pages at 375 / 768 / 1280 px, SEO tags, sitemap/robots,
  no analytics requests before consent. `crm.spec.ts` still covers demo form → lead.

## By hand

```
colima start
```

```
pnpm infra:up
```

```
pnpm db:seed
```

```
pnpm --filter @datascribe/cms migrate
```

```
pnpm --filter @datascribe/cms seed
```

```
pnpm dev
```

1. http://localhost:3001/admin: create the first CMS admin (asked on first visit).
2. Pages → Home: change the hero heading, Publish. Within a minute http://localhost:3010 shows it.
3. Pricing (http://localhost:3010/pricing): plan names and prices come from `SubscriptionPlan`; card
   taglines and labels come from the CMS Pricing page.
4. Resources: add a post in the CMS, publish, see it at `/resources` and `/resources/<slug>`.
5. Each page's SEO tab sets title, description and OG image. Check `/sitemap.xml` and `/robots.txt`.
6. Set `GA4_MEASUREMENT_ID` (e.g. `G-TEST1234`) in `.env`, restart web: the cookie banner appears on
   marketing pages; nothing loads until Accept; `/console` never loads it.
7. `/contact?kind=demo`: submit; the lead appears in the CRM and Mailpit (http://localhost:8025).
